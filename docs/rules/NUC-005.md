# NUC-005 Unchecked index

**Severity:** medium · **Default:** on

A "find" hint returns the index of a value in an array, and the circuit uses
the index without checking that the element there is the value searched for.
The prover can return any in-bounds index.

```rust
unconstrained fn find_hint(arr: [Field; 4], needle: Field) -> u32 { /* ... */ }

fn lookup(keys: [Field; 4], values: [Field; 4], key: Field) -> Field {
    // Safety: the index is bounds checked
    let i = unsafe { find_hint(keys, key) };
    values[i] // keys[i] == key is never checked
}
```

## Fix

```rust
assert(keys[i] == key);
```

## What the rule looks at

Integer hint results that reach an array index, or the compiler's
"Index out of bounds" check. The index counts as checked when some constraint
involves both the index and the hint's non-array arguments (the needle).

For library functions, the rule stays quiet when the index or the element read
is returned, because the caller may check it.
