# NUC-007 Narrowing cast of an unchecked Field

**Severity:** medium · **Default:** off

`x as u8` on a `Field` keeps the low 8 bits and silently drops the rest. If
the code then treats the `u8` as standing in for `x` (comparing it, using it
as an amount), any `x` with the same low bits passes.

```rust
fn check_limit(x: Field, limit: u64) {
    assert((x as u64) < limit); // x = 2^64 + 1 passes
}
```

## Fix

Range check the `Field` before narrowing when it is meant to fit:

```rust
x.assert_max_bit_size::<64>();
assert((x as u64) < limit);
```

## Why it is off by default

Truncation is often intended, for example taking the low byte of a hash. The
rule cannot tell intent apart, so it is noisy on real code. Enable it with
`--enable NUC-007` when auditing value-handling code.

## What the rule looks at

A `truncate` of a non-constant `Field` followed by a cast to the integer type
of that width, where the `Field` is not range checked to that width anywhere.
